A program that writes one Monday-morning joke to `/output/entry.txt` (138 characters, inside the 1–200 character gate): "Monday asked me for my weekend back. I handed it over, then it asked for Tuesday too, and I realized Monday is just a loan shark in a tie." Monday is personified as a loan shark collecting the weekend, then coming back for Tuesday too — the punch lands on the last image, and the joke only works on a Monday.

## Run it

```sh
python3 main.py
```
